งานอาร์ต UI เกม Wild meat-baww (ภาพแคปจากเกมจริง 24 พ.ย. 2026)
=====================================================

ตอนนี้ UI ทุกชิ้นยังเป็นกล่องสีเรียบๆ ที่โค้ดวาดขึ้นมาเอง ยังไม่มีภาพจริงสักชิ้น
ภาพในโฟลเดอร์นี้ใช้ดูว่าแต่ละชิ้นอยู่ตรงไหน มีอะไรบ้าง และขนาดประมาณเท่าไร
ข้อความในเกมเป็นภาษาอังกฤษ ฟอนต์ที่ใช้ตอนนี้ไม่มีภาษาไทย

A_UI_บนจอ  (ภาพหน้าจอ อ้างอิงขนาดจอ 1920x1080)
----------------------------------------------
A01 เมนูหลัก: ชื่อเกม + ปุ่ม START / SETTINGS / QUIT
A02 หน้าตั้งค่าเสียงในเมนูหลัก: หัวข้อ, สไลเดอร์ BGM / SFX, ปุ่ม BACK (ตอนนี้กล่องโปร่ง เห็นปุ่มข้างหลังทะลุ)
A03 เมนูหยุดเกม (กด ESC): PAUSED + ปุ่ม RESUME / SETTINGS / MAIN MENU
A04 หน้าตั้งค่าเสียงตอนหยุดเกม (ใช้หน้าตาเดียวกับ A02)
A05 เงินมุมขวาบน
A06 เลข +เงินที่เด้งขึ้นใต้ยอดเงินตอนได้เงิน
A07 แถบเตือนสีแดงกลางจอด้านบนตอนโจรขโมยอาหาร
A08-A10 หน้าร้านค้า 3 แท็บ (HUNT / COOK / STORE)
    ชิ้นที่ต้องมี: กรอบหน้าต่าง, หัวร้าน, ยอดเงิน, ปุ่มแท็บ (เลือกอยู่ / ไม่ได้เลือก), แถวสินค้า,
    ปุ่ม UPGRADE / BUY (กดได้ / เงินไม่พอ / MAX), ราคา (พอ = เหลือง, ไม่พอ = แดง), ปุ่ม EXIT
A11 หน้าจ้างพนักงาน: ใช้กรอบเดียวกับหน้าร้าน ไม่มีแท็บ มีปุ่ม SOON สำหรับของที่ยังล็อก
A12 แผงอัปเกรดหม้อ (โผล่ด้านล่างจอตอนยืนที่หม้อ): ชื่อหม้อ, เงิน, แถว Product Price / Production Speed
    (ตอนนี้หม้อไก่มีแค่แถวราคา), LV, ค่าเก่า -> ใหม่, ปุ่มราคา
A13 มือชี้สอนเล่น (ตอนนี้ใช้รูปมือจาก Kenney Cursor Pack ชั่วคราว) เด้งขึ้นลงเหนือสิ่งที่ต้องทำต่อ

B_UI_ในโลกเกม  (ลอยอยู่ในฉาก ขยายตามกล้อง)
------------------------------------------
B01-B02 ตัวเลขของในกระเป๋าเหนือหัวผู้เล่น เช่น 4/12 (เต็มแล้วเปลี่ยนเป็นสีแดง แต่ไม่ได้แคปไว้)
B03 หลอดเลือดสัตว์ โผล่หลังโดนตีครั้งแรก
B04 ป้ายสูตรบนหม้อ: ไอคอนเนื้อ + จำนวนที่รอต้ม -> ลูกศร -> ไอคอนอาหาร, พื้นสีเขียวคือหลอดความคืบหน้า
B05-B06 วงบนพื้นที่หม้อ: วงขาว = ยืนใส่เนื้อ (เขียวตอนยืนอยู่), วงเหลือง = ยืนเก็บอาหาร
B07-B08 ป้ายแคปซูลบอกจำนวนอาหารบนชั้นวาง (ไอคอน + ตัวเลข) และวงวางของหน้าชั้น
B09 โต๊ะคิดเงิน: วงยืนของผู้เล่น + หลอดคิดเงินสีเขียวเหนือหัวลูกค้า
B10 ป้ายจำนวนจานที่ลูกค้าถืออยู่ (แบบเดียวกับ B08)
B11 ป้ายบอกเมนูที่ลูกค้าอยากกิน (ตอนนี้เป็นคำว่า Chicken ตัวหนังสือเฉยๆ ควรมีฟองคำพูดหรือไอคอน)
B12 ลูกค้ารอนาน ตัวเปลี่ยนสีจากขาวเป็นส้มแดง (ไม่มีหลอดความอดทน ถ้าจะทำต้องวาดเพิ่ม)
B13 ลูกค้าสลบ: ไอคอนมึนที่โค้ดตั้งไว้ (อีโมจิ) ไม่ขึ้นในเกม ต้องวาดใหม่
B14 วงทองหน้าร้านค้า (เดินเข้าไปเพื่อเปิดหน้าร้าน)
B15-B16 วงจ่ายเงินหน้าประตูโซน ตัวเลขราคานับถอยหลังตอนจ่าย

C_ภาพเต็มจอ_ดูตำแหน่ง
----------------------
ภาพทั้งจอไว้ดูว่าแต่ละชิ้นวางตรงไหนเมื่อเล่นจริง

ที่ไม่มีภาพ (เขียนบรรยายไว้แทน)
-------------------------------
- เครื่องหมาย "!" สีแดงเหนือหัวโจรตอนขโมยของ (ช่วงแคปไม่มีโจรโผล่)
- แถบดำบน-ล่างจอตอนกล้องเลื่อนไปโชว์โซนใหม่ (เป็นแถบดำล้วน ไม่ต้องวาด)
- ป้ายราคาซื้อหม้อ/เครื่องผสมเนื้อที่ยังล็อก (ยังไม่โผล่ในฉากตอนแคป)
- ไม่มี UI เลือดผู้เล่น (เกมมีค่าเลือด แต่ยังไม่มีอะไรแสดง)
